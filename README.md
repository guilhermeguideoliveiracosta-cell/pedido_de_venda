# 🛒 *Sistema de Vendas*

**Um sistema simples de controle de estoque e vendas, desenvolvido em Python para praticar lógica de programação e conceitos básicos da linguagem.**

## 🛠️ *Tecnologias utilizadas*

-  **Python 3**

-  **Biblioteca random**

-  **Biblioteca time**

## ⚙️ *Funcionalidades*

📦 **Adicionar produtos ao estoque**

📋 **Consultar estoque**

🛍️ **Simular atendimento de cliente**

💰 **Calcular o valor das vendas**

💳 **Registrar pagamentos por Pix, dinheiro, débito e crédito**

🧾 **Fechar o caixa**

## ▶️ Como executar

1. **Instale o Python no computador.**

2. **Baixe ou clone este repositório**.

3. **Abra o terminal dentro da pasta do projeto.**

4. **Execute o programa:**<br>
python_main.py

## 💻 Demonstração

**Ao iniciar o programa, será exibido um menu:**

--- Pedidos de venda ---

1 - Adicionar no estoque<br>
2 - Conferir estoque<br>
3 - Atender cliente<br>
4 - Fechar caixa<br>
5 - Finalizar sistema<br>


**O sistema permite cadastrar produtos, consultar o estoque, simular vendas e acompanhar os valores recebidos em cada forma de pagamento.**

## 🎯 Objetivo

**Projeto desenvolvido para praticar Python, estruturas condicionais, loops, listas, dicionários, entrada de dados e lógica de programação.**<br>
